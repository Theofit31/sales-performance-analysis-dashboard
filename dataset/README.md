# Dataset

## Superstore Sales Dataset

This project uses the Superstore Sales dataset provided by Mathew K Analytics.

### Dataset Information

| Attribute | Description |
|---|---|
| File Name | superstore_sales.csv |
| Format | CSV |
| Total Records | 9,994 rows |
| Total Columns | 9 |
| Time Period | 2014–2017 |

### Dataset Columns

- Order Date
- Region
- State
- Category
- Sub-Category
- Segment
- Sales
- Profit
- Quantity

### Data Source

**Provider:** Mathew K Analytics

**Dataset Page:** https://www.mathewkanalytics.com/datasets/superstore-sales/

**Direct Download:** https://www.mathewkanalytics.com/data/superstore_sales.csv

### Usage in This Project

The dataset is used for:
- Sales performance analysis.
- Revenue and profitability analysis.
- Product category and regional performance analysis.
- Monthly sales trend analysis.
- Business insights and recommendations.
